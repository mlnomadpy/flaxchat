# Continue YAT representation training

The goal is better text, multilingual, and code representations from the existing trained weights. Read the repository's `docs/REPRESENTATION_TRAINING_RUNBOOK.md` before choosing data, launching a stage, or changing training infrastructure. In an installed copy, locate that document in the active FlaxChat checkout; do not assume paths relative to the installed skill resolve to the repository. Read only the relevant sections for a narrow task.

## Decisions that must remain explicit

- An exact resume restores the same stage's weights, optimizer, schedule, seed, sampler cursor, and immutable identity. A changed data recipe, objective, or incompatible schedule is a new stage initialized from prior trained weights, with a new output prefix and explicit optimizer policy. Never silently restart the model from random weights or overwrite its parent.
- Preserve the YAT architecture settings chosen by the user: fixed bias 1, fixed epsilon 0.01, and trainable alpha. BF16 kernel/residual changes require physical-TPU forward/backward and end-to-end evidence; CPU timing does not justify a TPU optimization.
- Contrastive loss alone is not a representation quality gate. Evaluate a pinned development suite covering retrieval, bitext alignment, semantic similarity, and code before and during continuation; reserve final benchmark test splits for reporting. Track language/task regressions alongside averages.
- The audited trainer now implements pinned dataset registries, optional homogeneous batches, language replay, complete relevance masking, best-checkpoint retention, pinned STS/language gates, and an opt-in exact encoder gradient cache. Their physical acceptance is unproven until receipts cover the active revision/topology. Earlier Global Voices replay still requires actual pinned data; teacher distillation and FSDP integration remain proposed. Read the current parser and implementation rather than inventing flags. Run model-free stage admission before allocation, then physical single-host qualification; add physical multi-host qualification before using multiple hosts. Preserve this implemented/unqualified distinction.
- Gradient accumulation changes update size; it does not by itself enlarge the simultaneous contrastive negative pool. Gradient caching must preserve the complete loss/gradient semantics, RNG, and global-negative behavior.
